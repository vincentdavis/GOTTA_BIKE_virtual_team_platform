One cached RiderProfile row instead of three fetches, two of them live. Everything here is display-only, so most values come from the JSON payload through the accessors on the model rather than from promoted columns -- the deep paths live there so there is one place to fix when zauth's shape moves. Deliberately NOT shown, because RiderProfile cannot supply them: * ZwiftPower rank -- zauth's ZpRider has no such column * race finishes/wins/podiums -- ProfileFull carries only the two peak ratings * best-ever rating -- needs a history table; this is an evictable snapshot * gender/country mismatch -- needs Zwift's raw values to disagree with The peak ratings are shown WITHOUT category badges for the same reason: zauth carries one racing category, the current one, so labelling a 90-day-old rating with today's tier would be a lie rather than a gap. {% endcomment %}
