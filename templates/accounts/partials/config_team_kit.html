{% comment %} Team kit management. Kits are rows rather than Constance settings, so this section posts to its own routes (team_kit_add / _edit / _make_current / _toggle_active) and each redirects back here with a message. The "current" kit is the one the team is working to get everyone into. A new season's kit is added and made current; the previous one is left as it was -- still active if riders should keep recording it, or retired. Only one kit can be current, and it must be active; the database enforces both, and the controls below say so before it has to. Every count on this page, and the member list, uses one population: team members, meaning anyone with a Discord login (apps.team.kits.team_members). That is what makes "haven't answered" an honest number. The verified filter narrows only the list, never the counts. {% endcomment %} {# --- the current kit, where it stands ------------------------------------------------ #} {% if current_kit_entry %}
