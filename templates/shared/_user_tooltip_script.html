{% comment %} Keeps the rider hover-card out of its scroll container. daisyUI positions .dropdown-content with `position: absolute`, so any ancestor with an overflow other than `visible` clips it. Nearly every table on the site is wrapped in `overflow-x-auto` -- and CSS forces the other axis to `auto` too, so those wrappers clip vertically as well. The card is then cut off for the last rows of every long table. z-index cannot help: the card is being clipped, not painted underneath. So on hover/focus we re-point the card at the viewport instead. No CSS is involved: daisyUI still owns showing and hiding it, and with JS off the behaviour is exactly what it was. Listeners are delegated from the document, so cards inside an HTMX swap work with no re-init. Included once from base.html -- not from the partial, which renders many times per page. {% endcomment %}
