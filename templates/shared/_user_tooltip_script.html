{% comment %} Opens the rider card on click, and keeps it open. It used to open on hover, which could not work: the card holds four links (Profile, Discord, ZP, ZR), and hover-triggered UI containing controls fails for everyone. A mouse user crossing the gap between the name and the card left both, so the card closed before they reached the buttons. Touch has no hover at all, and the name is a link, so tapping a rider on a phone just navigated -- the card was unreachable there entirely. It also failed WCAG 1.4.13, which requires content shown on hover to be hoverable, persistent and dismissable. So: click the name, the card opens and stays open. `popover="auto"` puts it in the top layer -- which is also what keeps it clear of the `overflow-x-auto` table wrappers that clip it and the `table-pin-col` sticky cells that paint over it -- and gives light dismiss and Escape for free.
