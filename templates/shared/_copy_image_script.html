{% comment %} Shared "copy this element as a PNG" mechanics, used by the ladder planner's per-tab capture buttons and the TTT planner's pull-schedule Copy button. The fiddly parts live here so there is one copy of them: expanding scroll wrappers so clipping is not baked into the image, pinning the element to its full scroll extent, and falling back to a download when the Clipboard API is unavailable (an insecure context, or a browser that has no ClipboardItem). Exposes window.copyAsImage(el, btn, {filename, excludeClass}) -> Promise. Callers own their own button placement and re-injection after HTMX swaps. {% endcomment %}
