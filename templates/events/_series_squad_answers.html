{% comment %} One squad's series answers, stage by stage: the riders x stages grid, its totals and, for the squad's captains, the riders' notes. Shared by the squad's results page and its card on the "Squads together" page; ``series_views.squad_results`` builds the values. ``is_event_admin`` (may manage this squad) shows each open stage's lineup button. On the results page it opens the dialog already on the page; with ``dialog_url`` (a card) it first loads this squad's dialog into ``#lineup-dialog-host``, since a page of cards holds one dialog at a time. That button is never disabled while it loads: a disabled button loses focus, and the dialog then has nowhere to send it back to when it closes. ``in_card`` leaves out the key, which that page shows once, and makes the notes heading an h3 under the card's h2. {% endcomment %}
