How this page works

Squads for {{ event.title }}.

Who can do what

{# table-cards: two columns on desktop, stacked action-then-who blocks on phones. #}
ActionWho can do it
Open this page Event admins, the event's Head Captain role, regional coordinators — plus any squad captain or vice-captain in this event.
Create or delete a squad Event admins, Head Captain role, regional coordinators.
Edit a squad, manage its availability, add or remove its riders The above, plus that squad's captain, vice-captain, or holder of the squad's Discord captain role.
Remove a rider from every squad at once Event admins, Head Captain role, regional coordinators (it spans squads, so it isn't a captain action).
Assign Riders page Event admins only.
Discord Roles page The Assign Roles permission, or the event's Head Captain role.

Captains see every squad listed here, but the controls only act on squads they lead. Superusers can do everything.

Adding a rider grants Discord access

  • Adding a rider gives them the squad's Discord role — that role is what lets them into the squad's text and voice channels.
  • If the squad has a Region role, they get that too.
  • Removing a rider takes both away again — except the region role is kept if they still belong to another squad that uses the same one.
  • If the rider was a captain or vice-captain, removing them also clears those and the captain Discord role.
  • Adding is additive: a rider can be in more than one squad, and adding them here does not remove them from another squad. The "Add rider" list groups riders by the squad they're already in, with unassigned riders first.
  • Riders can also join themselves through the squad's invite link, which grants the same roles.

Squad fields

Name
—
What the squad is called; also what the search box on this page matches.
Timezone
—
The squad's working timezone. Shown on the card and used by the timezone filter above.
Squad gender
—
Male, Female or COED. With Enforce gender on, a rider whose gender doesn't match is blocked (COED allows anyone).
Discord channel / Audio channel
—
Where the squad coordinates. Riders reach these via the squad's Discord role.
Squad Discord role
—
Added when a rider joins the squad and removed when they leave. This is the channel-access role.
Captain Discord role
—
Marks the squad's captains. Anyone holding it can manage this squad, the same as a named captain.
Region role
—
An extra role added on join and removed on leave, unless the rider is still in another squad with the same region role.
Regional coordinator role
—
This squad's coordinator, picked from the event's coordinator roles.
Zwift category min / max
—
The category range for the squad (A is strongest, E weakest; "min" is the weakest allowed). Each bound only blocks anyone when its Enforce box is ticked.
Women's Zwift category min / max
—
The same range applied to women's categories, with its own enforce boxes.
Zwift Racing category min / max
—
The same idea using ZwiftRacing categories, with its own enforce boxes.
Squad link
—
An optional external page for the squad.
Invite link
—
A shareable link that lets riders add themselves to this squad. Generate or regenerate it on the squad card.
Captain notifications
—
DM the captain and vice-captain when a squad member's verification record changes.

Good to know

  • Category and gender limits are checked when you add a rider. Tightening a limit later doesn't remove riders who are already in the squad.
  • A squad's Discord role has to start with one of the event's role prefixes; the choices are filtered to match.
  • The search box and the timezone filter combine, so you can narrow to one region and then search within it.
  • Greyed-out items in the Actions menu are ones your roles don't cover — hover them to see what's required.
