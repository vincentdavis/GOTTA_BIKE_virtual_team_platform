Each Status link (_signup_status_cell.html) fetches its signup's form into the box (HX-Target status-dialog-body); the script opens the dialog as the request starts, so a slow answer still shows something at once, and puts focus on the form when it arrives. Saving is an ordinary post that comes back to this page. Cancel, Escape and the backdrop close it, and focus goes back to the link that opened it. A bottom sheet on a phone, a centred box from 640px. {% endcomment %}
